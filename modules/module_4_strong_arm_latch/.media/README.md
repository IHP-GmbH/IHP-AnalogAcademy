# StrongARM Design Figures

These figures illustrate the circuit, simulation, and physical implementation described in the numbered Module 4 tutorials:

- `analog_flow_generic.png`: schematic-to-layout design and verification flow.
- `schem-basic.png` and `schem-final.png`: architectural and layout-compatible schematic views.
- `CMP7345_tb.png` and `CMP7345_tb_out.png`: nominal transient testbench and example waveforms.
- `CMP7345_tb_mm.png` and `CMP7345_tb_proc.png`: mismatch and process-variation waveform overlays.
- `CMP7345_tb_kickback.png`: input-source network for the kickback experiment.
- `CMP7345_tb_kickback_res.png`: example input-kickback waveforms.
- `layout-final.png` and `layout_diff_pair.png`: comparator and matched differential-pair layouts.
- `diff_pair.png`, `cc_pair_nmos.png`, and `cc_pair_pmos.png`: matched sub-block schematics.
- `layout_cc_pair_nmos.png` and `layout_cc_pair_pmos.png`: cross-coupled pair layouts.

Use the pinned `IHP__CMP7345` submodule and the conditions recorded in your own simulations when reporting results. Waveform illustrations show example behavior rather than guaranteed performance.
